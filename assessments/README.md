# Assessments

Self-checks to help you find your starting point and confirm what you've learned.

> **Planned.** Assessments are written in the final polish phase, once each level's lessons
> are published.

## What will be here

| File | Purpose |
|---|---|
| `placement.md` | A placement self-assessment: about 20 questions that suggest a starting level and a learning path |
| `level-0-quiz.md` to `level-7-quiz.md` | An end-of-level quiz for each level, mixing recall, application and "explain it to a colleague" questions |

## Format

- Questions test the learning objectives listed in each level's README.
- Every question links to the lesson that teaches it, so a wrong answer tells you what to reread.
- Answers sit in collapsed `<details>` blocks, so you can check yourself without spoilers.
- Questions are tagged 🟢, 🟡 or 🔴, so you can test at the depth you studied.
