# Learning Paths

Curated routes through the catalog for different roles. Each path tells you which lessons to
read and **how deep** to go in each: 🟢 core only, 🟡 core + practitioner, or 🔴 everything.

> **Draft.** These paths follow the approved outline. Lesson links are added as lessons are
> published, and the paths are refined in the final polish phase. Lesson IDs match
> [CURRICULUM.md](CURRICULUM.md).

Not sure where you stand? Take the placement self-assessment in [assessments/](assessments/README.md) first.
