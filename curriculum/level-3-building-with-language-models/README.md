# Level 3 — Building with Language Models

Build applications on top of language models: prompting, structured output, evaluation, semantic search, retrieval-augmented generation (RAG) and model adaptation.

**14 lessons · about 12.6 hours** of reading and code, plus exercises.

## Learning objectives

By the end of this level you will be able to:

- Write, structure and evaluate prompts.
- Build semantic search and a vector index from scratch.
- Build, evaluate and harden a RAG pipeline.
- Choose between prompting, RAG and fine-tuning.
