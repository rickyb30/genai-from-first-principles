# Level 4 — Agentic Systems

Move from single model calls to agents that use tools, plan, remember, collaborate and ask a human before risky actions.

**11 lessons · about 10.2 hours** of reading and code, plus exercises.

## Learning objectives

By the end of this level you will be able to:

- Implement tool calling and the agent loop.
- Apply planning, reflection, memory and multi-agent patterns.
- Design human approval, dry-run and rollback into agents.
- Build a guarded multi-step agent.
