# Level 0 — Orientation

Get your bearings. What generative AI is, where it came from, what it can and can't do, and how to use this catalog.

**6 lessons · about 2.6 hours** of reading and code, plus exercises.

## Learning objectives

By the end of this level you will be able to:

- Explain what generative AI is and how it relates to AI, ML and deep learning.
- Describe the main eras of AI history and why progress came in waves.
- Recognize the common ways generative systems fail, and decide how much checking an output needs.
- Choose a learning path and run the catalog's code examples.

## Setup

Level 0 needs very little: only L0-06 uses NumPy. From the repository root, either install this
level's pinned dependencies, or install the root `requirements.txt`, which covers every level:

```bash
python -m pip install -r curriculum/level-0-orientation/requirements.txt
```
