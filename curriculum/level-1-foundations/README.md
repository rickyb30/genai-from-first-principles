# Level 1 — Foundations for Generative AI

The math and neural-network basics that generative models are built from, taught by building. The first model you train already generates text, and the level ends with a neural character-level language model written in NumPy.

**10 lessons · about 9.2 hours** of reading and code, plus exercises.

## Learning objectives

By the end of this level you will be able to:

- Compute with vectors, probabilities, entropy and gradients.
- Train a model with gradient descent and recognize overfitting.
- Implement backpropagation and a tiny autograd engine.
- Build, train and evaluate a neural language model from scratch.
