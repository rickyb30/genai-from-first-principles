# Level 5 — Production AI Engineering

Run generative AI systems in production: evaluation as engineering, observability, inference performance and cost, serving architecture and reference architectures.

**11 lessons · about 11 hours** of reading and code, plus exercises.

## Learning objectives

By the end of this level you will be able to:

- Build evaluation gates and measure judge reliability.
- Trace LLM and agent workflows with open telemetry conventions.
- Reduce inference latency and cost, and model their trade-offs.
- Design serving architectures with routing, limits and fallbacks.
