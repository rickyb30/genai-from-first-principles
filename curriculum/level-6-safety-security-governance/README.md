# Level 6 — Safety, Security & Governance

Secure and govern generative AI systems: the threat landscape, layered defences, red-teaming, responsible AI and the major governance frameworks.

**13 lessons · about 12.2 hours** of reading and code, plus exercises.

## Learning objectives

By the end of this level you will be able to:

- Threat-model an LLM application and map risks to public frameworks.
- Demonstrate and mitigate prompt injection and related attacks.
- Measure bias in generated output and explain provenance methods.
- Summarize governance frameworks and write a system card.
