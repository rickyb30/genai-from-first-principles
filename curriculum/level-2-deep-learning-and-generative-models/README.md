# Level 2 — Deep Learning & Generative Models

How modern generative models work inside: tokens, embeddings, attention, the transformer, pretraining, post-training and decoding. Also covers the other families of generative models, such as diffusion. The capstone is TinyLM, a transformer you build yourself.

**15 lessons · about 13.8 hours** of reading and code, plus exercises.

## Learning objectives

By the end of this level you will be able to:

- Implement tokenization, embeddings and attention from scratch.
- Explain how language models are pretrained and post-trained.
- Implement decoding strategies and explain hallucination.
- Compare generative model families and build a toy diffusion model.
- Build TinyLM and expose it through the shared LLM interface.
